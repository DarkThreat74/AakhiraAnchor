Add dhikr/tasbih counter, Hijri dates, and more landing page features

Audit found incomplete features: the dhikr_sequences table existed and
had an admin API, but there was no user-facing UI or API. Hijri dates
were returned by AlAdhan but never displayed. Both are now built.

New features:

1. Dhikr/Tasbih Counter (/dhikr)
   - New user-facing GET /api/dhikr route (auth-protected)
   - New /dhikr page with full tasbih counter UI:
     - Arabic phrase display (Amiri font, RTL)
     - Transliteration and source citation
     - Large tap area for counting
     - Progress bar showing count / target
     - Vibration feedback (web Vibration API + Capacitor haptics)
     - Auto-advance to next dhikr when target reached
     - Sequence progress dots (tap to jump between dhikrs)
     - Prev/Next/Reset controls
     - "All complete" celebration screen with restart option
     - Graceful empty state when table not seeded
   - Nav links added to desktop sidebar and mobile top bar

2. Hijri Date Display
   - Prayer dashboard "Today" tab: Hijri date shown below Gregorian
     date in Amiri font, accent color
   - Calendar day view: Hijri date shown in DayDateHeader below the
     Gregorian date
   - Computed client-side via Intl.DateTimeFormat with islamic calendar
     (no API changes needed, works offline)

3. Landing page updated with 2 new feature cards:
   - Dhikr counter
   - Hijri calendar
