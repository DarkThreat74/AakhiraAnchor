Add Qibla compass, Sadaqah tracker, and GitHub-style prayer heatmap

Three new features built based on competitor research.

1. Qibla Compass (/qibla)
   - New lib/prayer/qibla.ts with great-circle bearing formula:
     θ = atan2(sin(Δλ)·cos(φ₂), cos(φ₁)·sin(φ₂) − sin(φ₁)·cos(φ₂)·cos(Δλ))
   - Haversine distance calculation to Kaaba (21.4225°N, 39.8262°E)
   - Cardinal direction conversion (N, NNE, NE, ... NNW)
   - New GET /api/qibla route (auth-protected, uses saved prayer location)
   - New /qibla page with:
     - Rotating compass dial with cardinal directions + tick marks
     - Kaaba 🕋 icon at the needle tip
     - Live compass via DeviceOrientationEvent (mobile only):
       - iOS 13+ permission request via requestPermission(true)
       - webkitCompassHeading on iOS, 360-alpha on Android
       - Desktop fallback: static bearing from North
     - Info panel: bearing°, cardinal, distance to Kaaba, user coordinates
     - "Enable live compass" button (requires user gesture on iOS)
   - Nav links in desktop sidebar + mobile top bar

2. Sadaqah Tracker (/sadaqah)
   - New sadaqah_logs table (migration 0013):
     id, user_id, amount (numeric 10,2), currency, category, note, date
   - Categories: sadaqah, zakat, fidyah, charity
   - New CRUD API (/api/sadaqah):
     - GET: returns logs + summary by category + grand total
     - POST: create with validation (positive amount, valid category,
       valid date, note max 500 chars, rate limited 20/min)
     - DELETE: with IDOR protection (user can only delete own logs)
   - New /sadaqah page with:
     - Summary cards: Total Given + per-category breakdown
     - Add form: amount, date, category pills, optional note
     - History list with color-coded categories, delete confirmation
     - Empty state with CTA
   - Nav links in desktop sidebar + mobile top bar

3. GitHub-style Prayer Heatmap (in Stats tab)
   - Analytics API now fetches 365 days and returns heatmapData
     (map of date -> prayer count 0-5)
   - New PrayerHeatmap component in PrayerDashboardClient:
     - 365-day grid grouped into weeks (columns of 7 days)
     - Color levels: gray=none, red=1-2, amber=3-4, green=all 5
     - Month labels above the grid
     - Day labels (Mon, Wed, Fri) on the left
     - Legend (Less → More)
     - Horizontal scroll on mobile
     - Tooltips showing date + prayer count
