Unified urgency-based due date system with compact badges

Created a shared due-date formatter (src/lib/homework/due-format.ts) that
replaces the inconsistent "tomorrow at 9:30 AM" / "in 3d" labels with a
compact, urgency-driven badge system used everywhere:

- Overdue: "2d OVERDUE · 9:30a" (red, bold)
- Today: "TODAY · 9:30a" (red, bold)
- Tomorrow: "Tomorrow · 9:30a" (amber, semibold)
- This week (2-3d): "Wed · 9:30a" (amber, medium)
- This week (4-6d): "Fri · 9:30a" (neutral)
- Later: "Sep 15 · 9:30a" (muted)

Key improvements:
- Compact time format: "9:30a" / "12p" instead of "9:30 AM" / "12:00 PM"
  keeps pill widths uniform regardless of the time value
- Day names (Wed, Thu) instead of "in 3d" so you immediately see WHEN
  something is due, not just how far away it is
- Color-coded urgency: red for overdue/today, amber for tomorrow/soon,
  neutral for later — matches patterns from Todoist, Notion, and other
  competitors
- Card-level tints: overdue/today/tomorrow cards get subtle background
  tints and left-border accents for visual urgency at a glance
- Today page header now shows urgency breakdown badges ("2 overdue",
  "3 due today", "1 tomorrow") instead of a generic "8 items need
  attention" that didn't convey when anything was due
- Both TodayTab and HomeworkClient use the same formatter so labels are
  identical across the app
