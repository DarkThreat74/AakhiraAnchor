Add prayer stats: makruh zones, goal line, on-time %, best streak, day-of-week

Competitor research (Agent Reach/Exa across 7 apps: Muslim Pro, Athan,
Pillars, Khushu, SalahStreak, Just Pray, Kerahat vakti) showed Waqt was
missing several common prayer-stats features. This commit adds them.

API changes (src/app/api/prayer-log/analytics/route.ts):
- Added bestStreak via new calculateBestStreak() in lib/prayer/checkin.ts
  (walks 3650 days backwards tracking longest complete-day run)
- Added onTimeCount/lateCount/onTimePct per prayer (50% window threshold)
- Added dayOfWeekStats: per-weekday consistency (Sun-Sat)
- Added totalPrayedAllTime, avgPrayersPerDay
- Added mostConsistentPrayer, mostMissedPrayer

UI changes (src/app/(app)/prayer/PrayerDashboardClient.tsx):
- Overview cards expanded from 4 to 8:
  Row 1: Current Streak, Best Streak, Complete Days, Masjid Rate
  Row 2: This Week, Avg/Day, Total Prayed, Top Prayer (+ work-on hint)
- Per-prayer breakdown now has 5 metrics (added On-Time %)
- Prayer time bar replaced with makruh-zone visualization:
  Green zone (0-33%): Ideal time
  Amber zone (33-66%): Acceptable
  Red zone (66-100%): Makruh (disliked)
  Dashed goal line at 33% boundary with ▼ marker
  Solid marker showing the user's average position
  Zone labels below the bar
- New Day-of-Week Consistency section:
  7 bars (Sun-Sat) showing consistency %
  Best day highlighted green, worst day highlighted red
  Reveals patterns like "Fajr is hardest on weekends"
