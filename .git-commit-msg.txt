Goal completion animation; homework sort filters with redesigned filter bar

Goal completion animation (TodayTab):
- When a goal is checked off, a slide-through animation plays:
  1. Row briefly highlights green (success confirmation)
  2. Checkmark pops in with scale animation
  3. Row slides right and fades out over 0.8s
- Works for both short-term and long-term goals
- Uncompleting (toggling back to active) does not animate
- CSS keyframes: goalCompleteSlide + checkmarkPop

Homework sort filters:
- Added 4 sort modes: Soonest, Ending, Priority, Latest
  - Soonest: closest due date first (default)
  - Ending: overdue items first, then closest due date
  - Priority: high priority first, then by due date
  - Latest: furthest due date first
- Sort applies to pending homework only

Redesigned filter bar:
- Priority and sort filters are now in separate rows
- Each row has a labeled section header (uppercase, tracked)
- Filter chips are grouped inside a pill-shaped container with
  padding, giving a segmented control appearance
- Active filter has solid background, inactive is transparent
- Sort buttons include icons (CalendarClock, AlertCircle, etc.)
- "Clear class" button shortened and moved to sort row
- Overall more compact and polished than the previous flat chips
