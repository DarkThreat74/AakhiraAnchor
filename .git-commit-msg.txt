List view - hide past events for today:
- For the current day only, events whose end time has passed are now
  hidden from the list
- Events still in progress (start time passed but end time not yet)
  continue to show
- Past and future days are unaffected - all events show as before
- Example: at 10 PM, a 9 AM event is hidden, but a 4-5 PM event that
  ended at 5 PM is also hidden. An event from 9:30-10:30 PM still shows.

Series event editing - view all occurrences:
- The "Apply changes to all N events" toggle now has a "View all" link
  next to it
- Clicking "View all" fetches and displays every event in the series
  as a scrollable list
- Each occurrence shows: day name, date, time range
- The currently-editing event is highlighted with "(editing)" label
- Each occurrence has an "Open" button that navigates to that day so
  the user can edit just that one occurrence without affecting others
- Each occurrence has a delete button to delete that single event
- Deleting from the list updates the list and series count in place
- Helpful hint text: "Tap Open to edit a single occurrence without
  affecting others"
- "Hide list" button collapses the list
