Fix Turnstile blocking signups; add show-more to goals long-term and habits in Today tab

Turnstile CAPTCHA fix — root cause: empty TURNSTILE_SECRET_KEY in .env:
- The site key was set but the secret key was blank, so the server
  couldn't verify tokens and rejected every signup with 403
- Server-side (turnstile.ts): when secret key is missing in production,
  now logs a warning and allows signup (relying on fingerprint,
  honeypot, rate limiting, time-trap) instead of hard-blocking
- When secret key IS set, full Turnstile verification is enforced
- Added action validation: server now checks that the token's action
  matches "signup" (defense against cross-action token replay)
- Dev mode: uses Cloudflare's test secret key (1x0000000000000000000000000000000AA)
  which always passes, instead of silently skipping verification

- Script load promise now resets on failure, allowing retry

  never resolves)

  when NEXT_PUBLIC_TURNSTILE_SITE_KEY is not set
