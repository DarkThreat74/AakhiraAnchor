Fun fact popup redesign - time-based intervals:
- Cards now appear on a 3-hour time-based schedule (every 3 hours from
  midnight: 00:00, 03:00, 06:00, 09:00, 12:00, 15:00, 18:00, 21:00)
- On first visit, the next show time is initialized to the next 3-hour
  mark
- Card stays visible until dismissed - it does not auto-dismiss
- The timer for the next card does NOT start until the current card is
  dismissed (X or Got it)
- When dismissed, next show time = now + 3 hours

Fun fact - X vs Got it behavior:
- X (close): card is saved as "current" and can reappear in the cycle.
  The same fact may be shown again at the next interval.
- "Got it" / "Explore Learn": card is marked as permanently seen (added
  to seen list in localStorage). It will never appear again. The next
  unseen card is chosen for the next interval.
- X button has tooltip: "Close - this card may appear again"
- "Got it" button has tooltip: "Mark as read - this card won't appear
  again"
