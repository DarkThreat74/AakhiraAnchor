Fix Goals bugs + add details/description support

Bugs fixed:
- exportAsImage: removed broken shareNative call that shared text without
  the image — now always downloads the PNG directly
- exportAsPdf: fixed image onload race condition where the promise could
  hang forever if the image was already cached/complete
- exportRef: moved export container to only wrap the goals list, not the
  "Add a goal" button and input fields
- handleEditSave: added optimistic update for title/description edits
  so the UI updates immediately even when offline (SW returns 202
  without data.goal)
- handleShareLink: now shows "Copied!" feedback even when native share
  succeeds, not just on clipboard fallback
- countCompleted: excluded archived goals from the total/done count
- ListRow onBlur: removed auto-save on blur to prevent race conditions
  with delete/add-child buttons — edit saves via Enter or Ctrl/Cmd+Enter

- Add goal form now has an optional description textarea
- Sub-goal creation also supports description
- Edit mode shows both title input and description textarea
- List view: "Details" toggle button appears under goals that have
  a description — click to expand/collapse

  expand/collapse pattern

  both POST and PATCH
