Fix goals DB save + redesign tree view

1. Goals not saving to database:
   - Root cause: handleEditSave sends description: null when the
     description field is empty. The PATCH /api/goals route did
     body.description.length on null, which throws a TypeError.
     The catch block returned 500 and the goal never persisted.
   - Fix: coerce null to empty string before length check and
     trim in the API route (body.description ?? "").

     -> green when done

     count, with green + check when all children complete
