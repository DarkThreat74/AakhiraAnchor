Add playcaptcha as fallback when Turnstile isn't configured

When NEXT_PUBLIC_TURNSTILE_SITE_KEY is not set, the signup page now
shows a playcaptcha claw machine challenge ("grab the right toy to
prove you're human") instead of a broken Turnstile widget.

New unified CaptchaWidget component (captcha-widget.tsx):
- If Turnstile site key is set → renders Cloudflare Turnstile widget
- If Turnstile site key is missing → renders playcaptcha ClawCaptcha
- Exposes same CaptchaHandle interface (reset()) for both modes
- onVerify callback receives a token string in both modes:
  - Turnstile: real cf-turnstile-response token
  - Play captcha: synthetic "playcaptcha-verified" token

Server-side (turnstile.ts):
- When TURNSTILE_SECRET_KEY is not configured in production, accepts
  the "playcaptcha-verified" token as valid
- Other security layers still apply (rate limit, honeypot, time-trap,
  fingerprint)
- When the secret key IS set, full Turnstile verification is enforced
